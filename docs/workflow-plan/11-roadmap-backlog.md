# 11 里程碑与任务清单

状态：规划草案；以下复选框是待办，不表示已经实施。依赖和任务边界优先于日历承诺。

## 1. 分期口径

通用平台为 W0–W6；既有游戏方案为 P0、P1、P1.5、P2、P3、P4，两组编号不可混用。

| 既有游戏阶段 | 平台依赖 | 单独计算的工作 |
| --- | --- | --- |
| P0 宿主验证 | 可与 W0 共享探测报告 | shelf / Remote 路径、模板资源、插件重复注册 |
| P1 游戏核心 | 不依赖 W4 流程层 | 创建 / 导入、构建、素材、版本、试玩预览和导出 |
| P1.5 游戏流程 | W1/W2 基础 + W4 包契约 + P1 | 角色转换、简报、规则、交付卡、流程和基础证据 |
| P2 基础画布 | 可在 P1 后独立推进 | 画布挂载、编辑 / 导出、媒体和工程引用 |
| P3 试玩协作 | P1、P1.5，按能力接自动试玩 | 测试 / Bug 双向联动、自动报告 |
| P4 媒体 / 发布 | 各可选能力自己的依赖 | 动效、语音、视频、隧道 / 公开发布 |

工作流平台 W4 不包含把 P1/P2/P3/P4 全部重做一遍。共享快照 / 审核 / 队列算平台任务；工程隔离、编辑器挂载、领域格式转换算各适配任务，避免重复或漏算。

素材扩展采用独立 S0–S4 编号，见 [15 素材工作流](15-asset-workflow-sprite-gen.md)。S0 本地试验可先做，S1 静态桥依赖 P1，S2 动画与 S3 静态生成可在 S1 后分别推进，S4 与 P4 媒体范围协调。正式工作流接入另依赖 W1/W2 及 W4 包注册；这些扩展不追加到原 W / P 阶段出口。

## 12. 估算与责任拆分

W0 完成前不提供总工期承诺。对每个任务填写实施负责人、评审人、依赖、最可能 / 保守人日、验证工作、迁移 / 回退工作和置信度；负责人列暂不绑定真实人员。

| 工作包 | 规模预判 | 主要不确定性 |
| --- | --- | --- |
| W0 | 小到中 | 宿主能力验证和现有工具隔离 |
| W1 | 大 | 文件 / DB 一致性、恢复、版本依赖 |
| W2 | 中到大 | 旧直写工具改造和多文档发布 |
| W3 | 中到大 | 动态配置、版本与编辑冲突 |
| W4 / P1.5 | 中到大，P1 另计 | 角色 / 工程适配和领域编辑 |
| W5 | 每包独立估算 | 长文本上下文和人审质量 |
| W6 | 另立估算 | 拓扑、并发、批量和可视化 |
| E01–E06 | 按所映射阶段单列增量 | 宿主实际模型路由、注入、工具隔离和收据 |
| C0/C1 | 先 Spike，再估算基础协同 | 产品级来源、双向交接和执行去重 |
| C2 | 独立估算 | 团队能力、预算、冲突和取消对账 |
| C3 | 需求验证后另估 | 模板整理与批量交互 |
| S0 | 独立技术试验后评估 | Python 依赖、Windows 行为、成品加工质量 |
| S1 | 以 S0 和 P1 接口为基线单列 | 素材候选桥、来源、冲突及正式流程适配 |
| S2 | 独立估算 | 图集 schema / 播放、挑帧副本和网页接入 |

v0.5 将 W0-07/08、W1-09/10、W2-08、W3-02 的人工节点重绑及 S3-03 明确计入增量；不是已经完成的交付。C1 复用同一服务的工作在原任务内重估，不另建聊天执行器；后端特有恢复在对应 S 任务计量，共用 journal / 协议只计一次。
