当前工作台的 `src/host/index.ts` 已有笔记、DEMO、测试、Bug 等工具注册与处理，`src/host/agent.ts` 已有派发、取消和事件读取，`src/host/agent-model.ts` 已有角色 / 模型 / 工具配置的提示词组装。接入先分离服务和入口、验证实际宿主能力，不将全部旧模块同时重构，也不把提示词声明当成权限证据。

## 2. 共用服务与责任

```text
手工界面 / DSH 工具 / 聊天任务 / 工作流节点
                 ↓ 身份、权限、参数校验
             共用业务工具服务
                 ↓
       Attempt / job 关联、结果 manifest
                 ↓
           校验、快照与采用服务
                 ↓
      调度器继续 / 人工待办 / 声明的发布动作
```

业务服务完成能力操作，不自行宣告某条流程已通过；调度器不重新实现生成或加工算法。相同 operation 的重连 / 重复点击复用执行身份；工作流重跑则创建新 Attempt。普通产品聊天和手工操作保留各自来源，不为它们伪造 WorkflowRun。

选定业务接口同时开放为 DSH tools，具体候选清单、HTTP / 服务映射和人工确认边界统一见 [03 第 3.1 节](03-node-contract-runtime.md#31-业务接口开放为-dsh-tools)。这属于共用工具服务的实施内容；工具名尚待 W0 冻结，不表示已完成注册或需要另建 MCP 服务。

长任务使用 03 的 submit / observe / collect / requestCancel / reconcile 协议及 08 的持久关联。阶段指纹包含真实连接身份、版本和有效输入；原始凭据不进入公开 manifest。下载失败恢复下载，已确认提交不再次购买；无可靠受理证据时保留 outcome_unknown。取消请求和实际已停止分开记录，不能以关闭界面或轮询结束视为停止。

## 3. 用户编辑确认是一个节点

统一类型为 `human.edit-confirm`，属于人工执行器，不占用等待期间的模型、进程或自动调度槽。实例名称可以是“修改简报”“确认模块结构”“章节审稿”“挑选素材”，执行规则相同。

```text
有人审：生成简报 → 用户编辑确认 → 生成规则 → 构建 / 校验
无人审：生成简报 → 生成规则 → 构建 / 校验
```

| 情况 | 行为 |
| --- | --- |
| 到达人工节点 | 创建固定输入的 HumanTask，打开对应产物编辑 / 预览，停止后继 |
| 只保存、自动保存或关闭页面 | 保存 Draft，不确认、不继续 |
| 不改原文、直接确认 | 允许；记录人工确认来源与输入版本 |
| 确认并继续 | 冻结 revision、校验 / 捕获、人工采用该节点输出，再调度后继 |
| 确认并暂停，或运行已经暂停 | 保存确认结果并保持运行暂停，不能抢跑后继 |
| 没有人工节点 | 机器校验通过后系统采用并自动继续，不附加隐藏内容审批 |
| 校验失败、缺输出或受理不明 | 停止并展示可处理原因；不能因为无人审而放行 |
| 等待时刷新 / 重启 | 恢复同一待办和最近已保存草稿，不重新生成上游 |
| 上游输入失效、取消或并发确认 | CAS / 幂等校验；保留草稿，拒绝过期确认或返回已确认结果 |

上游系统采用只表示运行内选用，不等于用户批准。人工节点产出自己的 Snapshot / human Adoption，不回写上游生成记录；下游必须绑定它的输出，才消费用户修改后的版本。机器报告的原始结果与证据只读；用户编辑意见 / 决策，与证据分开保存。编辑正文使相关报告失效时按新内容重新检查。

正式 notes / modules / 工程回写遵循 08 的 outbox 和基准校验。有人审时发布目标绑定人工节点输出，禁止在其上游自动采用时提前回写；无人审时可绑定自动节点的合法输出。无人工节点不扩展模型、文件、网络、费用或对外发布授权。

W1/W2 提供有 / 无人工节点两份固定模板；W3 支持用户增删、调序并发布新版本。移除人工节点必须显式重绑后继端口、最终输出和发布目标，不热改进行中运行。所需编辑器不可用时明确只读 / 外部副本能力，不能创建一个实际无法完成的编辑承诺。

## 5. 范围和回退

不引入 OhMyGame 的 Pi 运行时、Electron 主界面、会话库、完整插件市场或所有媒体供应商；不恢复暂停中的记忆库工作。本轮只修改规划，没有生产迁移、安装、模型调用或公开发布。

以后实际抽取源码时按文件记录来源 revision、改动和适用许可声明，素材与依赖另行核对；机制参考不意味着整体复制可直接运行。

共用服务适配失败保留原入口，关闭新执行器；人工节点恢复异常时停止后继、保留待办和草稿，不自动跳过；长任务对账异常保留 job / 收据，不以新提交掩盖。已发布模板保持不可变，旧隐藏审核定义导入时显式转换成节点并核对，不能静默变成全自动。
