## 4. 变更与回退规则

1. 新需求先归入模块及 W / P / E / C / S 工作包，明确增加 / 替换 / 延期，不只追加一行待办。
2. 变更快照、状态、完成契约或包版本协议时，更新 01/02/03 和相应迁移，不改已发布定义。
3. 技术验证不通过要记录实际结果和降级，不将“待验证”标成完成。
4. 阶段回退优先关闭入口 / 调度，不删除新增表、内容库或用户文件。
5. 旧报告保留历史结论；新复验追加环境和证据，不把过去唯一一次结果扩成普遍保证。

- [ ] 模板、运行、Attempt、快照、草稿和领域投影均有责任归属。
