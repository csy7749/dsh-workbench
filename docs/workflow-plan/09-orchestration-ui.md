# 09 节点配置与编排界面

状态：规划草案。依赖：01 至 05。首期界面与 W1/W2 同期，不等待自由画布。

## 1. 信息架构

```text
门户 → 选择工作区 / 创作产品
  工作流
    模板：复制、配置草稿、发布版本
    运行：当前等待、历史、失败、派生分支
    产物：当前采用、候选、草稿、历史
  任务 / 笔记 / 设计 / 资产 / 测试：原有入口与关联
```

工作流的产品类型由产品包决定，不把小说放进“研发 Bug”默认分类。可以先在既有产品页提供试点入口，包稳定后再扩门户。

[14 聊天协同](14-chat-workflow-studio.md) 增加三个相互关联的入口：产品工作室聊天、工作流运行、节点内协作聊天。产品聊天可将选段保存为候选，采用后映射输入；节点详情可打开“协作修订”。它们共用产物与执行状态，按 C0–C3 逐期开关上线，不把新工作室主界面加入原 W1/W2 完成条件。

## 2. 三阶段交互

| 阶段 | 用户可配置 | 限制 |
| --- | --- | --- |
| W1/W2 步骤列表 | 查看输入、执行者、自动进度，人工节点编辑 / 确认 | 固定线性模板，包含有 / 无人工节点示例 |
| W3 节点配置 | 复制模板、添加允许节点、删除可选节点、调序、绑定输出端口 | 校验必需节点、端口和循环，发布新版本 |
| W6 图编排 | 多分支 DAG、连线、折叠、批处理视图、分支比较 | 不开放任意脚本 / 无限循环 |

W3 就能通过节点配置工作流。W6 只增加复杂可视化和多分支能力，不把用户所需配置能力全部推迟。

## 3. 页面与动作

| 页面 | 必需信息 | 动作 |
| --- | --- | --- |
| 模板列表 | 类型、版本、依赖、能否执行 | 新建、复制、配置、导入、归档 |
| 定义草稿 | 节点、参数、端口、显式人工节点、机器校验、问题 | 保存、校验、发布 |
| 运行详情 | 固定版本、步骤列表、当前行动、预算与状态 | 暂停、继续、取消、派生运行 |
| 节点详情 | 输入快照、执行事件、候选、草稿、证据 | 运行、重试、修订、采用 |
| 产物详情 | 来源、内容、版本、差异、关联对象 | 编辑副本、恢复、导出 |

节点列表为主操作入口，画布只是同一模型的另一个投影。键盘、窄窗和错误排查不依赖拖拽。

## 4. 运行态布局

左侧步骤 / 节点，中间产物预览与编辑，右侧可折叠事件 / 会话；窄窗改为标签页。沿用既有主题 token 和 Shadow DOM；React 编辑器挂载需显式 dispose，弹窗 / portal / 菜单都在正确样式范围内。

等待人工时突出“确认并继续”，不要以持续旋转表示系统仍在计算。状态至少有文字、图标和行动提示；stale 与 failed 分别显示。

人工节点主按钮统一显示“确认并继续”，另有“保存草稿”“确认并暂停”；普通自动节点显示运行 / 已采用，不要求点下一步。模板列表清楚列出人审节点数量，全自动模板显示“无人工编辑确认节点”。添加 / 删除人工节点时展示后继输入及发布目标的重绑，不允许图上删了节点而发布仍指向旧草稿。

## 5. 模板配置规则

- 参数表单由 schema 生成，默认值、单位、长度、可选范围明确。
- 模型、团队、工具与技能从宿主能力目录选取；不可用项保留显示并解释。
- 输入绑定选择具体输出端口与采用版本，不允许静默绑定“最新文件”。
- 调序后检查依赖，违反顺序时阻止发布并定位边 / 节点。
- 新模板发布后提示新运行使用新版本，进行中运行不热更新。
- 输出可编辑性由节点契约决定；不可编辑工程可创建外部工作副本。

[13 执行配置](13-execution-profiles.md) 的扩展表单分别显示模型、角色、Skill、MCP 工具及继承来源；能力使用“已验证 / 仅已配置 / 不可用”状态。请求与实际配置、加载指纹和收据放在诊断展开区，缺能力的原因和可执行下一步在主界面可见。W2 可先用固定且已验证的配置，完整选择界面列 E04，避免扩大首期范围。

## 6. API 和可观测性方向

拟议分组：definitions / versions、runs / steps / attempts、artifacts / snapshots / drafts、adoptions / events / capabilities。

变更请求使用 POST + expectedRevision + idempotencyKey；事件用 seq 游标，优先宿主事件流，不可用时有界轮询。客户端卸载停止请求和监听；重连补取事件，不能靠 DOM 推测节点完成。

运行详情提供可复制 traceId、runId、attemptId 和脱敏错误摘要，技术诊断在展开区；默认产品路径展示用户需要的产物、错误和下一步。

## 7. 任务与验收

- U01：固定模板运行列表 / 节点详情，支持完整审核流程。
- U02：节点 schema 表单、定义草稿、发布 / 配置冲突。
- U03：运行恢复、事件游标、会话链接与明确取消结果。
- U04：stale 输入对比、影响后继列表和派生运行入口。
- U05：窄窗、键盘、主题切换和长文档使用测试。
- U06：W6 图布局和连线校验另估，不影响此前阶段交付。
- U07：有 / 无人工节点模板、待办恢复、原文确认、暂停中确认及节点删除后的端口重绑。

## 8. 风险与回退

界面复杂时先保留步骤列表，缩减无用指标；客户端版本落后时使用能力清单只读降级。新视图通过开关关闭后原模块仍可访问，但新运行只能只读或在支持版本中恢复，不能让旧客户端误写新 schema。
