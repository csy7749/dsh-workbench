## 交互目标

1. **打开就能看到画布**：产品流程默认显示画布；运行列表、执行详情和人工审核通过可切换的侧栏展示。模板入口直接展示模板画布。空状态提供“从游戏模板开始”和“新建空白图”，保留选择产品与项目的明确提示。
2. **节点像工作单元**：节点本体显示标题、类型、输入输出端口、关键参数与运行状态。简报、模型、角色、提示词和规则的常用参数可在节点内编辑；长文本及人审使用展开编辑器。清楚标出未接通的节点及原因。
3. **连线可理解、可修改**：从输出拖到输入，拖动时高亮兼容端口；不兼容时说明原因；允许选中线、删除和重接，避免误点即删除。配置线与数据线保持类型隔离。
4. **画布基本操作齐全**：画布平移、以光标为中心缩放、适配全部节点、定位选中节点；添加节点支持分类与搜索；选择、删除、复制、撤销 / 重做至少覆盖节点和连线编辑。快捷键仅在画布具有焦点时生效，文本输入不被拦截。
5. **编辑状态可靠**：可见保存状态；切换图、产品或视图时保护未保存内容。图、节点位置、连线与参数保存后可重开。无法识别的节点或边保留原始数据并标记缺失，禁止运行；导入错误不能静默删数据。
6. **运行与节点对应**：画布显示待运行、运行中、等待人工、成功、失败、过期；点击节点能看到本次运行输入、输出、校验和错误。明确区分“新建运行并推进下一步”与将来真正的“从选中节点运行”。

## 实施顺序与验收

### C0：定位入口与样式

- 核对 DSH 实际加载的插件位置、构建版本及重启后的产物；核对两个入口的可见性、产品选择和容器尺寸。
- 真机分别打开模板入口、产品流程入口和空状态，记录能否看见图、节点库、错误信息；出现空白时定位挂载、样式或接口失败。
- 验收：用户能指出正在使用的入口，并看到游戏模板的六个节点和五条连线。不能只以源码或 HTTP 测试判定通过。

### C1：可操作画布与数据保护

- 改为画布优先布局，提供节点内常用控件、搜索、适配视图、选线和重接；加入受焦点约束的基本快捷键、撤销 / 重做。
- 修复切换视图时的未保存数据保护；未知节点 / 边保留原始数据、只读提示与兼容恢复；保存和导入的版本冲突不覆盖原始图。
- 验收：在真实桌面中从空白图放入六个节点、配置、连线、移动、缩放、删除并撤销；保存、切换离开、重开后逐项一致。测试 100 节点以上时仍可操作，并记录环境和性能结果，不预设性能数字。

### C2：节点级运行体验与游戏闭环

- 将运行状态、错误与产物投影到画布节点；选中节点打开详情，人审编辑和确认仍受内核校验约束。区分编辑中的图与冻结的运行图。
- 优先用线性游戏模板验收：需求 → GDD → 规则 JSON → 机器检查 → 人工确认 → 文件导出。GDD 修改使规则和下游过期；规则修改后重新校验。
- 验收：使用真实 DSH 模型跑到人工审核；保存草稿、关页重开、确认 / 暂停、失败重试和导出均成功，导出内容与来源记录可核对。记录模型选择证据和真实运行环境。

#### C2 补充：产物预览

- 节点详情直接显示预览；运行总览保留短摘要，展开「查看完整产物」后使用同一个查看器。保留现有采用、失效和空产物提示。
- Markdown 默认渲染标题、列表、表格和代码块；JSON 默认按层级缩进，格式错误时提示并显示原文。两种格式都能切到可选取和复制的原文。其他内容按纯文本显示；Markdown 中的原始 HTML 只显示为文字，预览不加载外链图片。
- 运行详情返回预览格式，依据冻结的输出约定及已采用的内容。例如工程产物可预览 JSON 构建报告，条件检查预览的是报告而非内部传递载荷。兼容已有运行记录和缺少格式的旧接口响应，不需要迁移快照；无法判定时按纯文本查看。
- 仅调整读取和展示，不修改快照内容、产物采用、人审或导出行为。「原文」指运行详情所返回的产物内容。
- 验收：用带表格和代码块的 GDD、紧凑 JSON 构建报告、格式有误的 JSON 检查两个入口的预览、原文和回退行为；补查旧记录、过期产物和长文档。构建和自动化检查与实际桌面验收分别记录。

### C3：连线驱动的多分支执行

- 在放开任意分支之前，扩展冻结定义、输入绑定和执行调度，使每个节点读取所有连接到其输入端口的具体快照；按依赖关系计算过期范围。
- 首先支持确定性的分支与汇合；并行、条件分支、局部重跑和中断恢复分别增加测试与可见状态。若未实现，校验阶段拒绝相应图并说明原因。
- 验收：两条上游合流时每个端口收到正确快照；变更其中一路只使受影响节点过期；重启、失败、取消、迟到结果和重复提交均不产生错误采用。

### C4：进阶整理能力

按实际使用优先级再补分组框、注释、节点折叠、模板版本比较等；DAG 小地图定位与多选对齐已接入源码。子图、批处理、第三方节点安装和外部 ComfyUI 后端各自立项，不默认纳入上述交付。

### 当前剩余工作（先实现，再统一验收）

1. **完整 DAG 运行**：校验节点的通过/失败分支、跳过、双审核导出与两种汇合策略已实现。“任一命中”仍等待所有连接分支结束，仅合并有效输入；全部未命中时跳过汇合。通用多输出端口仍需契约与实现；当前采用确定性串行调度，并行另行扩展。
2. **持续执行和恢复**：宿主自动创建和派发独立会话、收集结果，并持久化派发阶段和租约；人工节点停下，确认后继续。创建、配置和发送各有 60 秒等待上限；发送超时视为结果未知，暂停而不重复发送。合成适配器已覆盖连续两步、崩溃隔离、准备期间暂停/取消/停用、卸载、超时和迟到响应，真实 DSH 会话创建、模型选择及工具边界尚未验收。超时不会声称远端会话已被取消。
3. **画布完整性**：端口兼容高亮、浏览器草稿恢复、小地图定位和多选对齐已接入；继续完善节点级执行、分组/注释/折叠、节点运行详情、服务端草稿与版本迁移。
4. **集中验收**：上述实现完成后再统一检查桌面画布、分支和汇合、人工审核、真实模型、产品包边界、HTTP 和真实数据；检查失败按具体问题修复并复验。
